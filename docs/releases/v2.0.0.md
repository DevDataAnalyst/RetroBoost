# RetroBoost 2.0.0: the FluentCleaner update 🕹️

**Clean 4,000+ apps, switch off Windows ads and telemetry, remove bloatware and schedule a silent clean, all in the retro text-mode UI.**

RetroBoost 2.0 brings the ideas of [**FluentCleaner**](https://github.com/builtbybel/FluentCleaner), the transparent, community-powered CCleaner alternative, into RetroBoost's terminal UI. FluentCleaner's engines were ported from C# to PowerShell, and its rule files ship in `data/`. Still free, still one readable script, still **no install, no admin needed, no network calls, no telemetry**. Thank you to FluentCleaner and to the Winapp2 project: credits and licenses are in [THIRD-PARTY-NOTICES.md](https://github.com/DevDataAnalyst/RetroBoost/blob/main/THIRD-PARTY-NOTICES.md).

## ✨ What's new

- 🧽 **APP CLEAN** (`A`): the community **winapp2.ini** database, 4,076 rules for browsers, Office, Adobe, chat apps, games and Windows traces. RetroBoost lists only the apps you have, grouped like FluentCleaner. **Only cache, temp, log, crash, dump, thumbnail and telemetry rules start ticked**; history, cookies and sessions are yours to tick. `S` shows what the ticked rules would free; the selected rule's paths are shown on screen.
- 🔕 **TWEAKS** (`T`): 98 Windows settings (ads, AI extras, appearance, Edge, Explorer, gaming, privacy, system, taskbar, updates) with a live **NOW** column, a recommended set (`A`) and **undo** (`[u]`). Every value is read back after writing. `[A]` rows need RetroBoost started as administrator; the result screen offers `X` to restart Explorer when a change needs it.
- 🗑️ **UNINSTALL** (`U`): Store apps and programs in one list, with the ones *put there to advertise or sell* flagged and Windows parts locked (`#`). Nothing is pre-ticked. Silent uninstall first, the program's own window last, each removal verified.
- ⏰ **AUTO**: `-Auto` cleans without a screen (Task Scheduler friendly), `-Auto -Shutdown` shuts down 60 s later, and **SETTINGS → AUTO-CLEAN** schedules it daily, weekly or at logon. The automatic run never stops your programs.
- 🧩 **BOOST+APP CLEAN** (Settings): let BOOST run your APP CLEAN ticks too. Off by default.
- 🧰 **Your own rules**: winapp2 `.ini` files in `%LOCALAPPDATA%\RetroBoost\custom\`, and exclusions in `config.json`.
- 🕹️ A two-column main menu (`B D A R P T U S H Q`), group headers you can jump between with `← →`, and an `ADMIN` badge when elevated.

## 🛡️ Safe by design, still

FluentCleaner's rules are powerful, so RetroBoost wraps them in guards no rule can get past:

- your **Documents, Desktop, Downloads, Pictures, Music, Videos and OneDrive** are never touched;
- the **whole Windows folder** is never touched (Windows cleans itself: `W` on the Disk screen);
- fresh temp files, browser-extension databases (password managers), Store app installs and installer caches stay;
- **files in use are skipped and not counted**, so sizes are honest; browser rules wait while that browser runs;
- registry: only the entries a rule names (recent-file lists, telemetry), never a hive, machine-wide keys only when elevated. No "orphan" registry cleaning.

The **sandbox self-test** now runs **33 checks**: on top of the 1.0 checks it proves the winapp2 engine (patterns, recursion, exclusions, files in use, registry keys), the folder guards, a tweak applied and undone on a throwaway registry key, a real silent uninstall of a throwaway program entry, and `-Auto`. CI runs it on Windows for every change.

## 📦 Install (2 minutes)

1. Install PowerShell 7 once: `winget install Microsoft.PowerShell`
2. Download **`RetroBoost-v2.0.0.zip`** below. Right-click it → *Properties* → tick **Unblock** → *Extract all*.
3. Double-click **`RetroBoost.cmd`**. Try `A` (APP CLEAN), `T` (TWEAKS) and `U` (UNINSTALL), or press **ENTER** on *BOOST NOW*.

Want a risk-free look first? Run `RetroBoost.cmd -Demo` (invented data, changes nothing), or `RetroBoost.cmd -DryRun` (your PC, nothing changed).

Upgrading from 1.0? Replace the folder; your settings and kill list in `%LOCALAPPDATA%\RetroBoost` are kept.

Requirements: Windows 10 or 11, PowerShell 7+, a terminal of at least 80×26 ([Windows Terminal](https://aka.ms/terminal) recommended).

## ⚠️ Known limitations

- **Not ported on purpose:** FluentCleaner's AI explanations and its winget uninstall step (both need the network). The **cookie keep-list** is not ported yet, so cookie rules start unticked ([roadmap](https://github.com/DevDataAnalyst/RetroBoost/blob/main/docs/ROADMAP.md)).
- The safe default ticks come from rule names (cache, temp, log…): a heuristic, shown on screen, easy to change with `SPACE`, `A` and `N`.
- `Winapp2.ini` is the copy bundled with FluentCleaner 26.11.11 (`260828-custom`). RetroBoost never downloads updates; add newer rules to `custom\`.
- Uninstalling cannot be undone by RetroBoost (Store apps can be reinstalled from the Microsoft Store). Some uninstallers relaunch themselves and finish after RetroBoost's check: they are then reported as *still there*.
- Moved the RetroBoost folder after setting AUTO-CLEAN? Set the schedule again.
- Unsigned script; Windows PowerShell 5.1 isn't supported; screenshots are rendered from `-Demo` data.

If RetroBoost ever touches something it shouldn't, that is the most important bug there is. Please tell us.
