# RetroBoost 1.0.0: first public release 🕹️

**Free up your C: drive, trim RAM and stop unwanted programs, in one click, from a retro text-mode UI.**

RetroBoost is a free, open-source PC tune-up for Windows, written in PowerShell. No install, no admin rights, no network calls, no telemetry. This is the first public release, and **we're looking for developers (and curious humans) from all over the world to help make it more powerful.** 🌍

## ✨ Highlights

- 🖱️ **One click.** `RetroBoost-OneClick.cmd` shows a 3-second countdown (ESC cancels), then runs **BOOST**: clean safe junk, trim RAM, close the programs on *your* kill list.
- 🧹 **Safe by design.** Only regenerable data: temp files older than a day, npm/pip/uv/Yarn/bun/NuGet caches, browser caches, installer downloads, VS Code leftovers, crash dumps. Recycle Bin and GPU caches start unticked. Documents, photos and downloads are never touched.
- 🛡️ **Protected programs.** Windows core, security tools and terminals can't be stopped from here. Windowed apps get a polite close first so they can save.
- 🔍 **Nothing hidden.** A plan screen before every action, `-DryRun`, a `-Demo` tour with invented data, and a log of everything it does.
- 🕹️ **The retro look.** BIOS boot splash, block-letter logo, DOS-style progress, three phosphor themes (blue, green, amber) and optional beeps.
- 🧪 **Tested.** A sandbox self-test proves that a dry run changes nothing and a real BOOST removes exactly the right things; CI runs it on Windows for every change.

## 🧭 Got a nearly full C: drive?

Follow the plan in **[docs/FREE-UP-C-DRIVE.md](https://github.com/DevDataAnalyst/RetroBoost/blob/main/docs/FREE-UP-C-DRIVE.md)**: measure, clear the safe junk with RetroBoost, let Windows clean its own system files, uninstall what you don't use, hunt big files, move instead of delete, then keep it clean. About 30 minutes; the first steps give the most space for the least risk.

## 📦 Install (2 minutes)

1. Install PowerShell 7 once: `winget install Microsoft.PowerShell`
2. Download **`RetroBoost-v1.0.0.zip`** below. Right-click it → *Properties* → tick **Unblock** → *Extract all*.
3. Double-click **`RetroBoost.cmd`**, press **ENTER** on *BOOST NOW*, press **ENTER** to confirm.

Want a risk-free look first? Run `RetroBoost.cmd -Demo`: it uses invented data and changes nothing.

Requirements: Windows 10 or 11, PowerShell 7+, a terminal of at least 80×26 ([Windows Terminal](https://aka.ms/terminal) recommended).

## ⚠️ Known limitations

- **RAM trim is temporary.** Windows refills memory on demand; closing heavy programs is what lasts. RetroBoost says so on screen.
- Only **user-level** cleanup. Windows' own junk (Update cache, previous installations) is left to Windows: press `W` on the Disk screen to open *Settings → Storage*.
- **Unsigned script.** Cautious tools may flag it; unblock the zip and read the (single) script first.
- Windows PowerShell 5.1 isn't supported yet.
- The protected list and temp-skip folder reflect the author's setup (`claude`) and aren't configurable yet.
- Screenshots in the docs are rendered from `-Demo` data; real terminal captures are still wanted.
